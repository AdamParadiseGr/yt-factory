# yt-factory: облачный конвейер YouTube Shorts (первый канал: детский)

Всё в облаке и бесплатно: GitHub Actions (сборка) + Gemini / Groq / OpenRouter (сценарии, через
ротатор ключей в n8n) + Cloudflare Workers AI (картинки FLUX) + MoneyPrinterTurbo (озвучка,
субтитры, монтаж) + Telegram (проверка) + n8n (расписание, кнопки, лимиты, очередь публикации).
Загрузка в YouTube Studio вручную: через API из неаудированного проекта видео становятся приватными.

```
n8n: расписание из таблицы ──► GitHub Actions: produce
                                 сценарий (серии, веса жанров, идеи, ниша)
                                 → переводы заголовков → картинки (Worker/FLUX)
                                 → озвучка + субтитры + монтаж (MoneyPrinterTurbo)
                                 → автопроверка → Telegram с кнопками
n8n: кнопки ──► Одобрить (копия в Drive) / Переделать / Другой заголовок / Отклонить
n8n: час публикации ──► пакет для Studio (заголовок, описание, теги, файл) ──► вы загружаете
Actions (раз в неделю): статистика, ниша, комментарии, веса разнообразия, сборник 16:9
Actions (ежедневно): список стран YPP, пороги YPP
```

> Ничего из этого не запускалось с реальными ключами, Telegram, YouTube, Google и n8n. Проверено на
> тестовых данных: тесты логики, прогон `plan → qc → localize → deliver` с подставными ответами
> модели, сборка 16:9 в ffmpeg, синтаксис всех скриптов и JavaScript в n8n, структура workflow.
> Первый запуск считайте пробным.

## Порядок

**Часть A. Конвейер без n8n (около 20 минут).** После неё `produce` запускается вручную.

1. Создайте **публичный** репозиторий GitHub и загрузите туда содержимое этой папки.
2. Cloudflare: `cd worker && npx wrangler deploy`, затем `npx wrangler secret put WORKER_TOKEN`
   (длинная строка). Запомните адрес `https://yt-factory-images.<поддомен>.workers.dev`.
   Бесплатно 10 000 нейронов в день, сброс в 00:00 UTC.
3. Ключи: Gemini (aistudio.google.com/app/apikey), Groq (console.groq.com/keys), по желанию
   OpenRouter. Несколько ключей Gemini дают прибавку лимита только с разных аккаунтов.
4. Telegram: бот через @BotFather, напишите ему `/start`, `chat.id` из
   `https://api.telegram.org/bot<TOKEN>/getUpdates`.
5. Секреты репозитория (Settings → Secrets and variables → Actions): `GEMINI_API_KEYS`,
   `GROQ_API_KEYS`, `IMAGE_WORKER_URL`, `IMAGE_WORKER_TOKEN`, `TELEGRAM_BOT_TOKEN`,
   `TELEGRAM_CHAT_ID`. Позже: `OPENROUTER_API_KEYS`, `N8N_LLM_URL`, `N8N_LLM_TOKEN`, `YT_API_KEY`,
   `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_TOKENS`.
6. Actions → produce → Run workflow: канал `kids`, количество `2`.

**Часть B. n8n.** Хостинг, таблица-панель, пять workflow, учётные данные: `n8n/README.md`.

**Часть C. Аналитика (после создания канала).** ID канала в `channels/kids.json`
(`youtube_channel_id`, вида `UC...`) и ключ `YT_API_KEY`. Часы просмотра и просмотры Shorts требуют
OAuth: в Google Cloud включите YouTube Data API v3 и YouTube Analytics API, создайте OAuth client
(Web) с redirect `https://developers.google.com/oauthplayground`, переведите приложение в **In
production** (иначе токен живёт 7 дней). В OAuth Playground (шестерёнка: свои client id и secret)
выберите область `https://www.googleapis.com/auth/yt-analytics.readonly`, войдите аккаунтом канала,
получите refresh token. Секреты: `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_TOKENS` вида
`{"kids":"<refresh token>"}`. Без этого трекер показывает подписчиков и загрузки, а часы и Shorts
отмечает как «нет данных».

## Детский канал: что нужно знать

- В Studio для каждого ролика ставится аудитория **Yes, it's made for kids**: ролик приходит с этим
  напоминанием, а перед публикацией оно повторяется в пакете.
- Для таких роликов YouTube отключает комментарии и персонализированную рекламу, поэтому доход на
  1000 просмотров обычно ниже. Дайджест комментариев для `kids` не работает (канал помечен
  `comments: false`), он есть у канала `stories`.
- Политика «неоригинального контента» (обновлена 16 июля 2026) называет однотипный, шаблонный и
  массово производимый контент среди главных причин потери монетизации. Для детского ИИ-контента это
  самый рискованный случай. Защита в конвейере: разные жанры и структуры, серии с постоянными
  героями, счётчик разнообразия, ваш просмотр каждого ролика. Ещё нужны ваши правки: меняйте жанры в
  панели, добавляйте свои идеи в `data/ideas.json`, снимайте лишнее.
- Автопроверка для детей строже: сценарий проверяется моделью на пугающее, небезопасное для
  подражания и слишком сложное. Модель ошибается, поэтому вы смотрите всё сами.
- Не используйте чужих персонажей, песни и стиль известных каналов.

## Скрипты

| Скрипт | Когда | Что делает |
|---|---|---|
| `plan.py` | каждый запуск `produce` | сценарии; жанры по весам; серии и «библия мира» (`data/world/`); идеи из комментариев; подсказки из ниши; теги |
| `localize.py` | после `plan.py` | заголовки и описания на языках из `localize`; приходят в Telegram, вносятся в Studio вручную (Details → Translations) |
| `qc.py` | после рендера | длительность, субтитры, пустые и одинаковые картинки (хэш), проверка сценария моделью |
| `deliver.py` | после `qc.py` | Telegram, журнал происхождения `data/provenance.json`, статус `pending` в `data/status.json`, кнопки при `APPROVAL_BUTTONS=1` |
| `country_watch.py` | ежедневно | официальный список стран YPP; сообщение, когда появится Узбекистан, и если страницу не удаётся прочитать три дня подряд |
| `ypp.py` | ежедневно, отчёт по понедельникам | подписчики, загрузки за 90 дней, часы за 12 месяцев, Shorts за 90 дней, прогноз даты по линейному тренду |
| `besttime.py` | еженедельно | лучшее окно публикации по вашим данным и оценка жанров |
| `diversity.py` | еженедельно | жанры, структуры, повторяющиеся первые фразы, серии; пересчёт `data/weights.json` |
| `niche.py` | еженедельно | популярные короткие ролики ниши и общие приёмы, без копирования заголовков |
| `comments.py` | еженедельно | идеи продолжений и вопросы зрителей, ничего не публикует |
| `compile.py` | еженедельно | сборник 16:9 из одобренных роликов за 7 дней (8–10 минут), главы в описании |

Тесты логики: `python3 -m unittest discover -s tests`.

## Недельный сборник

`produce` хранит готовые ролики 14 дней как артефакты запуска. `weekly` собирает сборник только из
роликов со статусом `approved` (его ставит кнопка «Одобрить»). Без n8n запустите weekly вручную с
`include_pending = 1`. Нужно не менее 8 роликов, длина до 10 минут. Файл приходит в Telegram, если
он меньше 50 МБ, иначе лежит в артефактах запуска. Посмотрите на первые сборники прежде, чем
публиковать: YouTube может счесть однотипные подборки малоценными.

## Монетизация и страна

Партнёрская программа YouTube недоступна в Узбекистане, пока Узбекистан не появится в официальном
списке. Конвейер набирает подписчиков и часы заранее, а `country_watch.py` сообщит, когда список
изменится. Пороги в `ypp.py` взяты из справки YouTube на момент написания, сверяйте с ней.

## Известные ограничения

- Edge TTS иногда отказывает с IP дата-центров; это серая зона по условиям Microsoft для
  коммерческого канала. Если шаг Render падает на озвучке, пришлите лог.
- MoneyPrinterTurbo по умолчанию тянет `main`: после первого удачного запуска замените
  `MPT_REF: main` в `produce.yml` на конкретный коммит.
- FLUX не гарантирует одинаковое лицо героя в разных сценах, получается лишь схожесть.
- Страница YouTube со списком стран разобрана по тексту, который я видел; если вёрстка изменится,
  скрипт сообщит об этом.
